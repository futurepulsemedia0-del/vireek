# Export schema reference

> Generated file. Do not edit. Regenerate with `node scripts/compliance/gen-export-schema.mjs --write`.
> Generated by scripts/compliance/gen-export-schema.mjs from supabase/migrations. Documents what the migrations define; it is not a dump of a live database.

## Formats

- **Core** (`vireek-export/2`): tar archive: manifest.json + one <table>.<seq>.ndjson per chunk. Importable.
- **Supplement** (`vireek-export-supplement/1`): tar archive: manifest.json + one <table>.ndjson per table. Export only, never accepted by import.

Every file is UTF-8 NDJSON (one JSON object per line), rows sorted by `id`, object keys sorted alphabetically.
The manifest lists each file with its row count and SHA-256. `user_id` and credential-like keys are removed from every row.

| arrays | JSON array |
| NULL | null |
