# Customer Advisory Board (CAB) kit

Docs-only kit for running a Vireek Customer Advisory Board. Nothing here is a legal document: items marked **[COUNSEL]** need a lawyer's review before use, and **[VERIFY]** marks facts or numbers the owner must confirm. Bracketed `<...>` values are blanks to fill in.

| Doc | Purpose |
|---|---|
| [charter.md](charter.md) | Why the board exists, what it can and cannot do |
| [selection-criteria.md](selection-criteria.md) | Who to invite, how to score and balance seats |
| [meeting-cadence.md](meeting-cadence.md) | Rhythm, preparation, follow-up |
| [agenda-template.md](agenda-template.md) | Copy-paste agenda for a 90-minute session |
| [feedback-to-roadmap-log-template.md](feedback-to-roadmap-log-template.md) | How feedback becomes a visible roadmap decision |
| [conflict-of-interest-rules.md](conflict-of-interest-rules.md) | Disclosure, recusal, confidentiality, gifts |

Note: CAB membership is **not** consent to be named or quoted publicly; public customer stories need their own verified, dated consent.
