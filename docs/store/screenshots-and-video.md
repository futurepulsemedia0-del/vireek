# Store media kit — Vireek Field

Sizes below were cross-checked against several 2026 guides; App Store Connect rejects wrong dimensions immediately, so treat its upload error as the final authority.

## Apple App Store
| Set | Required? | Accepted pixels (portrait) |
| --- | --- | --- |
| iPhone 6.9" | **Yes** (1–10 images) | 1320×2868 · 1290×2796 · 1260×2736 |
| iPhone 6.5" | Only if no 6.9" set | 1284×2778 · 1242×2688 |
| iPad 13" | Only if iPad is supported (it is: `UISupportedInterfaceOrientations~ipad`) | 2064×2752 · 2048×2732 |
PNG or JPEG, RGB, no transparency. App preview video resolution must match the screenshot size of that device class.

## Google Play
- Phone screenshots: min 2, max 8, 16:9–9:16, each side 320–3840 px (use 1080×1920 or 1080×2340).
- 7" and 10" tablet screenshots (strongly recommended — tablet layouts are ranked on tablets).
- Feature graphic 1024×500 PNG/JPEG, hi-res icon 512×512 PNG (generated by `npm run native:assets`).
- Promo video = a public YouTube URL (no upload).

## Shot list (same 6 scenes, light + dark, English first)
1. **Today** — list of today's jobs with status dots and a visible swipe action ("Complete" in green).
2. **Job brief** — address, tap-to-call and Navigate buttons in the thumb zone.
3. **Capture** — photo + voice note + barcode scan, with the offline/"queued" sync badge visible.
4. **Offline** — airplane-mode banner with "3 changes waiting to sync", then the synced state.
5. **Messages** — job thread with unread badge on the app icon.
6. **Security** — App lock (Face ID) and Haptics/Low-data settings.
Use the demo account from `review-notes.md`; seed with `demo-seed.sql`. Never show real customer names or addresses.
